# 光谱波长校准台

校准员提交标称波长与实测波长。独立领取进程按允差写出合格或超差。页面轮询直到结论出现。
已结案行可由巡检在「复议台」填理由复议回队：回待处理、清空结论与理由、复议次数加一；领取进程重新仲裁后，原结论与重写结论理由写进任务履历，复议理由长期保留。

|------|------|

| 接口 | http://localhost:8195 |

| inspector | insp123456 | 只读，但可对已结案行复议 |

## 复议流程

1. 顶部导航进入「复议台」（首页不挂复议按钮），表中列出所有已结案（done）行。
2. 仅巡检（inspector）可填复议理由并点「复议回队」；校准员的输入与按钮均禁用，接口亦返回 403。
3. 复议后该行回到待处理，结论与理由清空，`review_count` 加一，履历记录复议理由/人/时间及原结论。
4. worker 重新领取仲裁后，履历补写重写结论、重写理由与结案时间；复议理由仍保留。
5. 待处理行不可再次复议（409），空理由拒绝（400）。
6. 在任务详情页底部查看完整复议履历与复议次数。

## 启动

```bash
cd projects/16-spectrum-wavelength-desk
docker compose up --build
```

## 验收

1. calibrator 登录后，种子「氦灯-587」合格、「汞灯-546」超差。
2. 再提交超差样条，先待处理再出超差。
3. inspector 不能提交。
4. inspector 进复议台，对种子「氦灯-587」（合格）填理由复议：行回待处理、结论理由清空、复议次数变 1；worker 再结案后仍为合格，任务详情履历保留复议理由与原/重写结论。
5. calibrator 在复议台不可填写或点复议；直接调接口被拒（403）。
6. 待处理行复议被拒（409）。
